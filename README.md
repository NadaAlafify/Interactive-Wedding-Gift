# Interactive Wedding Gift & Invitation Website

##  Description
A personalized, highly interactive digital wedding invitation and gift webpage dedicated to a close friend. This creative project showcases a minimalist and elegant design built from scratch, utilizing animations and interactive elements to create an emotional and memorable user experience.

When the user interacts with the page by clicking the main button, it triggers dynamic content reveals and custom background audio.

##  Live Demo
Experience the interactive gift here: (https://nadaalafify.github.io/Interactive-Wedding-Gift/)

##  Tech Stack
- **HTML5:** Structuring the multi-layered card components and layout.
- **CSS3:** Custom responsive design featuring elegant pastel color palettes, soft shadows, rounded typography, and floating background animations.
- **JavaScript (Vanilla):** Implemented to handle DOM manipulation, click event triggers, and the **Web Audio API** for the seamless background music activation.

##  Key Features & Interactivity
- **Interactive Button Trigger:** A beautiful call-to-action button (`افتحي هديتك`) that unlocks the hidden card content and starts the background audio simultaneously.
- **Audio Integration:** Programmed safely according to modern browser autoplay policies (audio triggers strictly on user interaction).
- **Elegant Typography & Layout:** Well-spaced sections displaying congratulatory messages and Quranic verses in a polished aesthetic.
- **Creative CSS Animations:** Smooth transition effects and floating elements that match the celebratory theme.
